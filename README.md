# React Dev Spotlight

A small React-based landing page that highlights selected GitHub repositories with clean UI and responsive design. Built to showcase full-stack and frontend skills in a quick, focused project.

## Tech Stack

- React (SPA)
- Modern tooling (to be added: Vite or similar)
- CSS utility framework (e.g. TailwindCSS) or custom styling

## Goals

- Demonstrate clean component structure and state management
- Consume GitHub API (or mock data) to list repositories
- Provide a simple, attractive portfolio entry for GitHub
